## ✅ Features Available in Theme Manager

### 1. 📸 Logo Upload
**Kya kar sakte ho:**
- School logo upload karo (PNG, JPG, GIF, WEBP)
- Current logo ka live preview dekho
- Ek click mein apply karo

**Kaise karein:**
1. "Upload School Logo" section mein jao
2. "Choose File" pe click karo
3. Apna logo select karo (200x200 pixels recommended)
4. "Upload & Apply Logo" dabao
5. Done! ✅

---

### 2. 🖼️ Hero Background Image Upload ⭐ NEW!
**Kya kar sakte ho:**
- Homepage ki large background image change karo
- Current hero image ka preview dekho
- High-quality widescreen images upload karo

**Kaise karein:**
1. "Upload Hero Background Image" section mein jao
2. "Choose File" pe click karo
3. Widescreen image select karo (1920x600 pixels recommended)
4. "Upload & Apply Hero Image" dabao
5. Homepage refresh karo aur dekho! ✅

**Best Practices:**
- Use high-quality images (10MB max)
- Widescreen format (16:9 ratio)
- School building ya students ki photos best hain
- Image mein text readable hona chahiye

---

### 3. 🏫 School Information (Quick Edit)
**Kya change kar sakte ho:**
- ✏️ **School Name** - Website pe har jagah dikhega

**Kaise karein:**

## 💡 Pro Tips

1. **Logo Upload:**
   - Best size: 200x200 pixels
   - Use PNG with transparent background
   - Max file size: 5MB

2. **Hero Image:**
   - Best size: 1920x600 pixels (widescreen)
   - High quality images for best results
   - Max file size: 10MB
   - School building photos work great!

3. **School Name:**
   - Ye naam website ke har page pe dikhega
   - Header, footer, aur title mein use hoga

4. **Theme Colors:**
   - Primary Color: Main website color (header, buttons)
   - Secondary Color: Background (usually white)
   - Accent Color: Highlights (badges, borders)

5. **Save Karna:**
   - Har section ka apna save button hai
   - Changes instant apply hote hain
   - Refresh karein website ko results dekhne ke liye
